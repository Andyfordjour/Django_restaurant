MySQL

MySQL — Complete Setup Guide

STEP 01

Install MySQL in WSL

MySQL is not installed by default in WSL. Run these commands in your WSL terminal to install and start it. The installation will take a minute or two.

bash
# Update package list first
sudo apt update

# Install MySQL server
sudo apt install mysql-server -y

# Start MySQL service
sudo service mysql start

# Verify it is running
sudo service mysql status
Auto-start tip: MySQL does not start automatically when you open WSL. You need to run sudo service mysql start each time you open a new WSL session before running your Spring Boot app.
STEP 02

Create the Database and User

By default MySQL has a root user with no password. Log in and create a dedicated database and user for your app. Using a dedicated user is better practice than using root directly.

bash
# Log into MySQL as root (no password needed first time)
sudo mysql

# Inside MySQL shell — run these one by one:

# 1. Create the database
CREATE DATABASE studentsdb;

# 2. Create a user with a password
CREATE USER 'springuser'@'localhost' IDENTIFIED BY 'password123';

# 3. Give the user full access to the database
GRANT ALL PRIVILEGES ON studentsdb.* TO 'springuser'@'localhost';

# 4. Apply the changes
FLUSH PRIVILEGES;

# 5. Exit MySQL shell
EXIT;
Change the password: Replace password123 with a password of your choice. Just remember it — you will need it in application.properties.
STEP 03

Update pom.xml — Swap the Driver Dependency

students/pom.xml

You need to remove the H2 dependency and add the MySQL connector. Open pom.xml in your project and find the H2 dependency section. Remove it completely and replace it with the MySQL connector shown below.

Find and remove this block from your pom.xml:
xml — REMOVE THIS
<!-- REMOVE this H2 block -->
<dependency>
    <groupId>com.h2database</groupId>
    <artifactId>h2</artifactId>
    <scope>runtime</scope>
</dependency>
Add this MySQL block in its place:
xml — ADD THIS
<!-- ADD this MySQL connector -->
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <scope>runtime</scope>
</dependency>
STEP 04

Update application.properties

src/main/resources/application.properties

Replace the entire contents of your application.properties file with the MySQL configuration below. This tells Spring Boot how to connect to MySQL instead of H2. The ddl-auto=update setting means Spring Boot will automatically create and update your database tables based on your entity classes — you never write SQL manually.

properties
# MySQL Connection
spring.datasource.url=jdbc:mysql://localhost:3306/studentsdb?useSSL=false&serverTimezone=UTC
spring.datasource.username=springuser
spring.datasource.password=password123
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

# JPA / Hibernate
spring.jpa.database-platform=org.hibernate.dialect.MySQLDialect
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
PropertyValueWhat it does
datasource.urljdbc:mysql://localhost:3306/studentsdbConnects to MySQL on port 3306, database named studentsdb
usernamespringuserThe MySQL user you created in Step 02
passwordpassword123The password you set in Step 02
ddl-auto=updateupdateAuto-creates and updates tables — data persists between restarts
show-sql=truetruePrints SQL queries to the console so you can see what's happening
STEP 05

Run and Test with MySQL

Make sure MySQL is running, then start your Spring Boot app the same way as before. Your data will now persist even after stopping and restarting the app.

bash — Terminal 1 (make sure MySQL is running)
# Start MySQL if not already running
sudo service mysql start

# Run Spring Boot — same command as before
cd ~/students
./mvnw spring-boot:run
What to look for: You should see Tomcat started on port 8080 and no errors. If you see a connection refused error, MySQL is not running — run sudo service mysql start first.
bash — Terminal 2 (Angular stays the same)
cd ~/student-app
ng serve
bash — Verify data persists in MySQL
# Log into MySQL and check your data
sudo mysql -u springuser -p studentsdb

# Inside MySQL shell:
SELECT * FROM student;
EXIT;
PostgreSQL

PostgreSQL — Complete Setup Guide

STEP 01

Install PostgreSQL in WSL

PostgreSQL is not installed by default in WSL. Run these commands to install it and start the service. The installation will take a minute or two.

bash
# Update package list first
sudo apt update

# Install PostgreSQL
sudo apt install postgresql postgresql-contrib -y

# Start PostgreSQL service
sudo service postgresql start

# Verify it is running
sudo service postgresql status
Auto-start tip: PostgreSQL does not start automatically when you open WSL. You need to run sudo service postgresql start each time you open a new WSL session before running your Spring Boot app.
STEP 02

Create the Database and User

PostgreSQL uses a default system user called postgres. Switch to that user to access the PostgreSQL shell, then create a dedicated database and user for your Spring Boot app.

bash
# Switch to the postgres system user
sudo -i -u postgres

# Open the PostgreSQL shell
psql

# Inside psql shell — run these one by one:

# 1. Create a user with a password
CREATE USER springuser WITH PASSWORD 'password123';

# 2. Create the database owned by that user
CREATE DATABASE studentsdb OWNER springuser;

# 3. Grant all privileges
GRANT ALL PRIVILEGES ON DATABASE studentsdb TO springuser;

# 4. Exit psql shell
\q

# 5. Exit the postgres system user session
exit
Change the password: Replace password123 with a password of your choice. Just remember it — you will need it in application.properties.
STEP 03

Update pom.xml — Swap the Driver Dependency

students/pom.xml

Remove the H2 dependency and add the PostgreSQL driver. Open pom.xml, find the H2 block, remove it, and replace it with the PostgreSQL driver shown below.

Find and remove this block from your pom.xml:
xml — REMOVE THIS
<!-- REMOVE this H2 block -->
<dependency>
    <groupId>com.h2database</groupId>
    <artifactId>h2</artifactId>
    <scope>runtime</scope>
</dependency>
Add this PostgreSQL block in its place:
xml — ADD THIS
<!-- ADD this PostgreSQL driver -->
<dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <scope>runtime</scope>
</dependency>
STEP 04

Update application.properties

src/main/resources/application.properties

Replace the entire contents of your application.properties file with the PostgreSQL configuration below. Notice the port is 5432 (PostgreSQL's default) instead of MySQL's 3306. The dialect also changes to tell Hibernate it is talking to PostgreSQL instead of MySQL.

properties
# PostgreSQL Connection
spring.datasource.url=jdbc:postgresql://localhost:5432/studentsdb
spring.datasource.username=springuser
spring.datasource.password=password123
spring.datasource.driver-class-name=org.postgresql.Driver

# JPA / Hibernate
spring.jpa.database-platform=org.hibernate.dialect.PostgreSQLDialect
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
PropertyValueWhat it does
datasource.urljdbc:postgresql://localhost:5432/studentsdbConnects to PostgreSQL on port 5432, database named studentsdb
usernamespringuserThe PostgreSQL user you created in Step 02
passwordpassword123The password you set in Step 02
ddl-auto=updateupdateAuto-creates and updates tables — data persists between restarts
show-sql=truetruePrints SQL queries to the console so you can see what's happening
STEP 05

Run and Test with PostgreSQL

Make sure PostgreSQL is running, then start your Spring Boot app the same way as always. Your data will now persist even after stopping and restarting the app.

bash — Terminal 1 (make sure PostgreSQL is running)
# Start PostgreSQL if not already running
sudo service postgresql start

# Run Spring Boot — same command as before
cd ~/students
./mvnw spring-boot:run
What to look for: You should see Tomcat started on port 8080 and no errors. If you see a connection refused error, PostgreSQL is not running — run sudo service postgresql start first.
bash — Terminal 2 (Angular stays the same)
cd ~/student-app
ng serve
bash — Verify data persists in PostgreSQL
# Log into PostgreSQL and check your data
sudo -i -u postgres
psql -d studentsdb -U springuser

# Inside psql shell:
SELECT * FROM student;
\q
exit

Files That Stay Exactly the Same

These files require zero changes regardless of which database you choose. This is the power of Spring Boot's abstraction — the database layer is completely decoupled from your business logic and UI.

StudentController.java — No changes needed

java
@RestController
@RequestMapping("/api/students")
@CrossOrigin(origins = "http://localhost:4200")
public class StudentController {
    private final StudentRepository repository;
    public StudentController(StudentRepository repository) {
        this.repository = repository;
    }
    @GetMapping
    public List<Student> getAllStudents() { return repository.findAll(); }
    @PostMapping
    public Student addStudent(@RequestBody Student student) { return repository.save(student); }
}

student.service.ts — No changes needed

typescript
@Injectable({ providedIn: 'root' })
export class StudentService {
  private apiUrl = 'http://localhost:8080/api/students';
  constructor(private http: HttpClient) {}
  getAllStudents(): Observable<Student[]> { return this.http.get<Student[]>(this.apiUrl); }
  addStudent(student: Student): Observable<Student> { return this.http.post<Student>(this.apiUrl, student); }
}

Troubleshooting — Common Errors

Error: Communications link failure / Connection refused

Cause: The database server is not running. This is the most common error.

fix
# For MySQL:
sudo service mysql start

# For PostgreSQL:
sudo service postgresql start

Error: Access denied for user 'springuser'

Cause: Wrong username or password in application.properties, or the user was not created correctly.

fix — MySQL
sudo mysql
ALTER USER 'springuser'@'localhost' IDENTIFIED BY 'password123';
FLUSH PRIVILEGES;
EXIT;
fix — PostgreSQL
sudo -i -u postgres
psql
ALTER USER springuser WITH PASSWORD 'password123';
\q
exit

Error: Unknown database 'studentsdb'

Cause: The database was not created yet, or the name in application.properties doesn't match.

fix — MySQL
sudo mysql
CREATE DATABASE studentsdb;
GRANT ALL PRIVILEGES ON studentsdb.* TO 'springuser'@'localhost';
FLUSH PRIVILEGES;
EXIT;

Error: Could not load driver class

Cause: The database driver dependency is missing from pom.xml or the H2 dependency was not fully removed.

Fix: Double check your pom.xml — make sure the H2 dependency is completely removed and the correct MySQL or PostgreSQL dependency has been added. Then stop and restart Spring Boot with ./mvnw spring-boot:run to force a fresh download of dependencies.

Error: Table 'studentsdb.student' doesn't exist

Cause: The ddl-auto property is missing or set incorrectly. With update, Spring Boot creates the table automatically on first startup.

Fix: Make sure spring.jpa.hibernate.ddl-auto=update is in your application.properties. This tells Hibernate to create tables automatically from your entity classes. Restart Spring Boot after adding it.
