ExtComment

ext.training.acm.plugins.comment.model Class
Represents a comment in the system. A comment can be attached to any ArkCase object such as a Complaint or Case File. This data is saved in the ext_comment database table.

participantsThe list of participants who have access to this comment.
restrictedWhether this comment is restricted to certain users. Defaults to false.
creatorThe username of the person who created this comment.
createdThe date and time this comment was created.
modifierThe username of the person who last changed this comment.
modifiedThe date and time this comment was last changed.

ExtCommentAPIController

ext.training.acm.plugins.comment.web.api Class
Handles incoming HTTP requests for comment operations. Exposes endpoints to get, save, and delete comments. All endpoints are available under: /api/v1/plugin/ext/comment. After every create, update, or delete, an event is fired so other parts of the system (like audit logging) can react.
