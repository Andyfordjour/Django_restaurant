How Angular & Spring Boot Work Together

Angular is the frontend — what the user sees in the browser. Spring Boot is the backend — handles logic, processes data, and talks to the database. They never communicate directly. They talk through a REST API using HTTP requests and JSON. Think of it like a restaurant: Angular is the customer, the REST API is the waiter, Spring Boot is the kitchen.
LayerTechnologyRolePort
FrontendAngularThe UI the user sees and clicks in the browser4200
BridgeREST APIHTTP requests and JSON responses between the two layers—
BackendSpring BootBusiness logic, data processing, database communication8080
DatabaseH2 (In-Memory)Stores student records during the session — no install needed—
HTTP MethodEndpointWhat it does
GET/api/studentsReturns all students as a JSON array
POST/api/studentsReceives a student JSON object and saves it to the database

STEP 02

Student.java — Data Model

src/main/java/com/example/students/Student.java

This class maps to a database table. Spring Boot reads the annotations and automatically creates a STUDENT table with ID, NAME, and EMAIL columns. @Entity marks it as a table. @Id marks the primary key. @GeneratedValue makes the database auto-generate IDs (1, 2, 3...) so you never set it manually. The getters and setters let Spring Boot read and write the fields when converting between Java objects and JSON.

java✎ editable
package com.example.students;

import jakarta.persistence.Entity;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;

@Entity
public class Student {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    private String name;
    private String email;

    public Student() {}

    public Student(String name, String email) {
        this.name = name;
        this.email = email;
    }

    // Getters and Setters
    public Long   getId()    { return id; }
    public String getName()  { return name; }
    public String getEmail() { return email; }
    public void   setId(Long id)        { this.id = id; }
    public void   setName(String name)   { this.name = name; }
    public void   setEmail(String email) { this.email = email; }
}

STEP 04

StudentController.java — REST API Handler

src/main/java/com/example/students/StudentController.java

@RestController means every method returns JSON data, not a webpage. @RequestMapping sets the base URL for all endpoints in this class. @CrossOrigin is critical — it allows Angular on port 4200 to call Spring Boot on port 8080. Without it the browser blocks cross-origin requests due to the CORS security policy. @GetMapping handles HTTP GET requests. @PostMapping handles HTTP POST. @RequestBody tells Spring to read the incoming JSON and convert it into a Java Student object automatically.

java✎ editable
package com.example.students;

import org.springframework.web.bind.annotation.*;
import java.util.List;

@RestController
@RequestMapping("/api/students")
@CrossOrigin(origins = "http://localhost:4200")
public class StudentController {

    private final StudentRepository repository;

    public StudentController(StudentRepository repository) {
        this.repository = repository;
    }

    @GetMapping
    public List<Student> getAllStudents() {
        return repository.findAll();
    }

    @PostMapping
    public Student addStudent(@RequestBody Student student) {
        return repository.save(student);
    }
}

STEP 03

student.service.ts — API Communication

src/app/services/student.service.ts

The service handles all HTTP communication with Spring Boot. HttpClient is Angular's built-in HTTP tool injected via the constructor. Both methods return Observables — Angular's way of handling asynchronous operations (things that take time, like network requests). The component subscribes to these and reacts when the data arrives. By isolating API calls in a service the component stays clean and focused only on UI logic.

typescript✎ editable
import { Injectable } from '@angular/core';
import { HttpClient } from '@angular/common/http';
import { Observable } from 'rxjs';
import { Student } from '../models/student';

@Injectable({ providedIn: 'root' })
export class StudentService {

  private apiUrl = 'http://localhost:8080/api/students';

  constructor(private http: HttpClient) {}

  getAllStudents(): Observable<Student[]> {
    return this.http.get<Student[]>(this.apiUrl);
  }

  addStudent(student: Student): Observable<Student> {
    return this.http.post<Student>(this.apiUrl, student);
  }
}

STEP 05

app.component.ts — Component Logic

src/app/app.component.ts

The component holds the state (list of students, form values, messages) and the logic (what happens on load, what happens when you click Add). ngOnInit() fires automatically when the component is created — this is where you load initial data. subscribe() waits for the Observable to resolve. The next callback runs on success, error on failure. After adding a student the form resets and a success message shows for 3 seconds via setTimeout().

typescript✎ editable
import { Component, OnInit } from '@angular/core';
import { CommonModule } from '@angular/common';
import { FormsModule } from '@angular/forms';
import { StudentService } from './services/student.service';
import { Student } from './models/student';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [CommonModule, FormsModule],
  templateUrl: './app.component.html',
  styleUrl: './app.component.css'
})
export class AppComponent implements OnInit {

  students: Student[] = [];
  newStudent: Student = { name: '', email: '' };
  successMessage = '';

  constructor(private studentService: StudentService) {}

  ngOnInit(): void {
    this.loadStudents();
  }

  loadStudents(): void {
    this.studentService.getAllStudents().subscribe({
      next: (data) => this.students = data,
      error: (err) => console.error('Error loading students', err)
    });
  }

  addStudent(): void {
    if (!this.newStudent.name || !this.newStudent.email) return;

    this.studentService.addStudent(this.newStudent).subscribe({
      next: (student) => {
        this.students.push(student);
        this.newStudent = { name: '', email: '' };
        this.successMessage = 'Student added successfully!';
        setTimeout(() => this.successMessage = '', 3000);
      },
      error: (err) => console.error('Error adding student', err)
    });
  }
}

What Happens Behind the Scenes

📄 When the page loads

1
Angular starts and calls ngOnInit()
2
Sends GET /api/students to Spring Boot
3
Spring Boot runs SELECT * FROM STUDENT on H2
4
Returns a JSON array back to Angular
5
Angular renders rows using *ngFor

➕ When you add a student

1
You type — [(ngModel)] updates the component instantly
2
Click Add Student — addStudent() is called
3
Angular sends POST /api/students with JSON body
4
Spring Boot saves it and H2 assigns an auto ID
5
Angular adds it to the table instantly — no reload

Add Spring Security with JWT so only authenticated users can manage students. Teaches backend security and token-based auth.

MySQL — Complete Setup Guide

STEP 01

Install MySQL in WSL

MySQL is not installed by default in WSL. Run these commands in your WSL terminal to install and start it. The installation will take a minute or two.

bash✎ editable
# Update package list first
sudo apt update

# Install MySQL server
sudo apt install mysql-server -y

# Start MySQL service
sudo service mysql start

# Verify it is running
sudo service mysql status
Auto-start tip: MySQL does not start automatically when you open WSL. You need to run sudo service mysql start each time you open a new WSL session before running your Spring Boot app.
STEP 02

Create the Database and User

By default MySQL has a root user with no password. Log in and create a dedicated database and user for your app. Using a dedicated user is better practice than using root directly.

bash✎ editable
# Log into MySQL as root (no password needed first time)
sudo mysql

# Inside MySQL shell — run these one by one:

# 1. Create the database
CREATE DATABASE studentsdb;

# 2. Create a user with a password
CREATE USER 'springuser'@'localhost' IDENTIFIED BY 'password123';

# 3. Give the user full access to the database
GRANT ALL PRIVILEGES ON studentsdb.* TO 'springuser'@'localhost';

# 4. Apply the changes
FLUSH PRIVILEGES;

# 5. Exit MySQL shell
EXIT;
Change the password: Replace password123 with a password of your choice. Just remember it — you will need it in application.properties.
STEP 03

Update pom.xml — Swap the Driver Dependency

students/pom.xml

You need to remove the H2 dependency and add the MySQL connector. Open pom.xml in your project and find the H2 dependency section. Remove it completely and replace it with the MySQL connector shown below.

Find and remove this block from your pom.xml:
xml — REMOVE THIS✎ editable
<!-- REMOVE this H2 block -->
<dependency>
    <groupId>com.h2database</groupId>
    <artifactId>h2</artifactId>
    <scope>runtime</scope>
</dependency>
Add this MySQL block in its place:
xml — ADD THIS✎ editable
<!-- ADD this MySQL connector -->
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <scope>runtime</scope>
</dependency>
STEP 04

Update application.properties

src/main/resources/application.properties

Replace the entire contents of your application.properties file with the MySQL configuration below. This tells Spring Boot how to connect to MySQL instead of H2. The ddl-auto=update setting means Spring Boot will automatically create and update your database tables based on your entity classes — you never write SQL manually.

spring.datasource.username=springuser
spring.datasource.password=password123
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

# JPA / Hibernate
spring.jpa.database-platform=org.hibernate.dialect.MySQLDialect
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true

@RestController

Troubleshooting — Common Errors

Error: Communications link failure / Connection refused

Cause: The database server is not running. This is the most common error.

fix✎ editable
# For MySQL:
sudo service mysql start

# For PostgreSQL:
sudo service postgresql start

Error: Access denied for user 'springuser'

Cause: Wrong username or password in application.properties, or the user was not created correctly.

fix — MySQL✎ editable
sudo mysql
ALTER USER 'springuser'@'localhost' IDENTIFIED BY 'password123';
FLUSH PRIVILEGES;
EXIT;
fix — PostgreSQL✎ editable
sudo -i -u postgres
psql
ALTER USER springuser WITH PASSWORD 'password123';
\q
exit

Error: Unknown database 'studentsdb'

Cause: The database was not created yet, or the name in application.properties doesn't match.

fix — MySQL✎ editable
sudo mysql
CREATE DATABASE studentsdb;
GRANT ALL PRIVILEGES ON studentsdb.* TO 'springuser'@'localhost';
FLUSH PRIVILEGES;
EXIT;

Error: Could not load driver class

Cause: The database driver dependency is missing from pom.xml or the H2 dependency was not fully removed.

Fix: Double check your pom.xml — make sure the H2 dependency is completely removed and the correct MySQL or PostgreSQL dependency has been added. Then stop and restart Spring Boot with ./mvnw spring-boot:run to force a fresh download of dependencies.

Error: Table 'studentsdb.student' doesn't exist

Cause: The ddl-auto property is missing or set incorrectly. With update, Spring Boot creates the table automatically on first startup.

Fix: Make sure spring.jpa.hibernate.ddl-auto=update is in your application.properties. This tells Hibernate to create tables automatically from your entity classes. Restart Spring Boot after adding it.
