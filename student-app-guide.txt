================================================================================
       STUDENT MANAGEMENT APP — ANGULAR + SPRING BOOT FULL STACK GUIDE
================================================================================

A beginner-friendly full stack application using:
  - Spring Boot (Backend / REST API) — runs on port 8080
  - Angular       (Frontend / UI)     — runs on port 4200
  - H2 Database   (In-memory DB)      — no setup required

--------------------------------------------------------------------------------
HOW THEY WORK TOGETHER
--------------------------------------------------------------------------------

Think of it like a restaurant:

  Customer  →  Angular (what the user sees and interacts with)
  Waiter    →  REST API (the communication bridge)
  Kitchen   →  Spring Boot (the brain — handles logic and data)

Angular and Spring Boot never talk directly. They communicate through
HTTP requests using JSON format:

  Angular                   REST API                  Spring Boot
  -------                   --------                  -----------
  "Get me all students" →  GET /api/students     →   Fetches from DB
                        ←  Returns JSON           ←   Sends back data
  [displays the list]

--------------------------------------------------------------------------------
PROJECT STRUCTURE
--------------------------------------------------------------------------------

  Spring Boot (Port 8080)
  ├── Student.java                ← The data model (id, name, email)
  ├── StudentRepository.java      ← Talks to the H2 database
  └── StudentController.java      ← Handles API requests

  Angular (Port 4200)
  ├── models/student.ts           ← Shape of the data
  ├── services/student.service.ts ← Calls the Spring Boot API
  ├── app.component.ts            ← Component logic
  ├── app.component.html          ← What the user sees
  └── app.component.css           ← Styling

--------------------------------------------------------------------------------
API ENDPOINTS
--------------------------------------------------------------------------------

  GET  /api/students      → Returns all students as a JSON array
  POST /api/students      → Accepts a student object and saves it

STEP 2 — Student.java (The Data Model)
----------------------------------------
Location: src/main/java/com/example/students/Student.java

  package com.example.students;

  import jakarta.persistence.Entity;
  import jakarta.persistence.GeneratedValue;
  import jakarta.persistence.GenerationType;
  import jakarta.persistence.Id;

  @Entity
  public class Student {

      @Id
      @GeneratedValue(strategy = GenerationType.IDENTITY)
      private Long id;
      private String name;
      private String email;

      public Student() {}

      public Student(String name, String email) {
          this.name = name;
          this.email = email;
      }

      // Getters and Setters
      public Long getId()          { return id; }
      public String getName()      { return name; }
      public String getEmail()     { return email; }
      public void setId(Long id)   { this.id = id; }
      public void setName(String name)    { this.name = name; }
      public void setEmail(String email)  { this.email = email; }
  }

STEP 4 — StudentController.java (REST API)
-------------------------------------------
Location: src/main/java/com/example/students/StudentController.java

  package com.example.students;

  import org.springframework.web.bind.annotation.*;
  import java.util.List;

  @RestController
  @RequestMapping("/api/students")
  @CrossOrigin(origins = "http://localhost:4200")
  public class StudentController {

      private final StudentRepository repository;

      public StudentController(StudentRepository repository) {
          this.repository = repository;
      }

      @GetMapping
      public List<Student> getAllStudents() {
          return repository.findAll();
      }

      @PostMapping
      public Student addStudent(@RequestBody Student student) {
          return repository.save(student);
      }
  }

  NOTE: @CrossOrigin(origins = "http://localhost:4200") is important —
  it allows Angular to call Spring Boot without being blocked by the browser.

STEP 3 — student.service.ts (API Communication)
-------------------------------------------------
Generate the service:
  ng generate service services/student

Location: src/app/services/student.service.ts

  import { Injectable } from '@angular/core';
  import { HttpClient } from '@angular/common/http';
  import { Observable } from 'rxjs';
  import { Student } from '../models/student';

  @Injectable({
    providedIn: 'root'
  })
  export class StudentService {

    private apiUrl = 'http://localhost:8080/api/students';

    constructor(private http: HttpClient) {}

    getAllStudents(): Observable<Student[]> {
      return this.http.get<Student[]>(this.apiUrl);
    }

    addStudent(student: Student): Observable<Student> {
      return this.http.post<Student>(this.apiUrl, student);
    }
  }

STEP 5 — app.component.ts (Component Logic)
---------------------------------------------
Location: src/app/app.component.ts

  import { Component, OnInit } from '@angular/core';
  import { CommonModule } from '@angular/common';
  import { FormsModule } from '@angular/forms';
  import { StudentService } from './services/student.service';
  import { Student } from './models/student';

  @Component({
    selector: 'app-root',
    standalone: true,
    imports: [CommonModule, FormsModule],
    templateUrl: './app.component.html',
    styleUrl: './app.component.css'
  })
  export class AppComponent implements OnInit {

    students: Student[] = [];
    newStudent: Student = { name: '', email: '' };
    successMessage = '';

    constructor(private studentService: StudentService) {}

    ngOnInit(): void {
      this.loadStudents();
    }

    loadStudents(): void {
      this.studentService.getAllStudents().subscribe({
        next: (data) => this.students = data,
        error: (err) => console.error('Error loading students', err)
      });
    }

    addStudent(): void {
      if (!this.newStudent.name || !this.newStudent.email) return;

      this.studentService.addStudent(this.newStudent).subscribe({
        next: (student) => {
          this.students.push(student);
          this.newStudent = { name: '', email: '' };
          this.successMessage = 'Student added successfully!';
          setTimeout(() => this.successMessage = '', 3000);
        },
        error: (err) => console.error('Error adding student', err)
      });
    }
  }

================================================================================
WHAT HAPPENS WHEN YOU USE THE APP
================================================================================

  When the page loads:
    1. Angular starts and calls ngOnInit()
    2. Sends GET request to http://localhost:8080/api/students
    3. Spring Boot fetches all students from H2
    4. Returns JSON list to Angular
    5. Angular displays them in the table

  When you add a student:
    1. You fill the form and click "Add Student"
    2. Angular sends POST request to http://localhost:8080/api/students
    3. Spring Boot receives it and saves to H2 database
    4. Spring Boot sends back the saved student with a generated ID
    5. Angular adds it to the table instantly

================================================================================
IMPORTANT NOTES
================================================================================

  H2 In-Memory Database:
    Since H2 runs in memory, all data is lost when Spring Boot stops.
    This is perfect for learning. To persist data permanently, switch
    to MySQL or PostgreSQL later.

  Ports:
    Spring Boot runs on → http://localhost:8080
    Angular runs on     → http://localhost:4200

  @CrossOrigin:
    This annotation on StudentController allows Angular (port 4200) to
    call Spring Boot (port 8080). Without it the browser blocks the request.
